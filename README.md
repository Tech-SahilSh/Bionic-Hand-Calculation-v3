# 🤖 Bionic-Hand-Calculation-v3
This project is a bionic hand calculation system made using Python and Arduino, with a 3D printed hand attached to ESP32 and 5 servo motors. The system is designed to mimic human hand movements.

## Short Description
The bionic hand is controlled using a combination of Python scripts and Arduino code, allowing for precise movement and calculation of hand gestures.

## Features
* 3D printed bionic hand with ESP32 and 5 servo motors
* Controlled using Python scripts and Arduino code
* Precise movement and calculation of hand gestures
* Real-time monitoring and control using index.html

## How to Run Locally
1. Clone the repository: `git clone https://github.com/your-username/Bionic-Hand-Calculation-v3.git`
2. Navigate to the project directory: `cd Bionic-Hand-Calculation-v3`
3. Install required Python libraries: `pip install -r requirements.txt` (if available)
4. Upload the Arduino code to the ESP32 board using the Arduino IDE
5. Run the Python script: `python app.py`
6. Open index.html in a web browser to monitor and control the bionic hand
